# Data sets referenced by this book's code

Per `front_matter/companion_website.typ`: "no real patient-level or
commercially sensitive trial data is used anywhere in this book." All
data referenced in the book's R code is either (a) generated inline by
the code itself (synthetic/simulated, `set.seed()`-reproducible), or
(b) a placeholder filename illustrating what a reader's own file would
look like, not a real dataset this repository ships.

## What belongs here once built

Per the book's planned Appendix F ("Data sets used in the book") and
`companion_website.typ`'s `/data/` description: synthetic and
openly-licensed example datasets only, with a full data dictionary in
the appendix. Two honest paths to fill each placeholder above, to be
decided per-file as each chapter is finalised for public release:

1. **Replace the code with an inline-generated synthetic dataset**
   (preferred where plausible — most of this book's other chapters
   already do this, e.g. Chapter 4's toy treatment-cost tibble built
   directly in R rather than loaded from a file). This keeps the
   example fully self-contained and removes the external-file
   dependency entirely.
2. **Ship a real synthetic/simulated CSV** in this folder, built with
   a documented `set.seed()` and a short data-dictionary entry in
   Appendix F, when the worked example specifically needs to
   demonstrate an IMPORT step itself (Chapter 5's whole point in
   §5.4 is teaching `readr`/`readxl`/`haven`/`DBI` import mechanics,
   so a real file-on-disk is arguably pedagogically necessary there,
   not swappable for inline generation without weakening the lesson).

Do not place any real patient-level, commercially licensed, or
otherwise non-redistributable data here, per the book's own stated
policy.
