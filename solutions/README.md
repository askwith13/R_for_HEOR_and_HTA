Per `front_matter/companion_website.typ`'s planned `/solutions/`
folder and the Table of Contents' Appendix G ("Solutions to exercises").

## Status: not applicable yet

No chapter currently includes formal end-of-chapter exercises — the
35-chapter cron-paced drafting process (Chapters 1-18 complete as of
this folder's creation) has not yet introduced an exercises section
per chapter, and Appendix G itself has not been drafted (back-matter
appendices are written after the main chapters, per the book's
stated pace). This folder exists now so the companion repository's
structure matches `companion_website.typ` from day one, rather than
appearing later as an unexplained addition.

## What belongs here once built

One subfolder per chapter that has exercises
(`solutions/chNN_slug/`), each containing a runnable `.R` solution
script per exercise, cross-referenced by exercise number against that
chapter's printed exercise list and against Appendix G's own solution
walkthroughs. Mirror the naming convention already used in `code/`
(`code/chNN_slug/NN.R`) for consistency.

If and when exercises are added to the chapter-writing workflow, the
`heor-hta-book-writer` skill should be updated with a corresponding
per-tick step here, parallel to the existing image-tracking,
table-tracking, and code-extraction steps.
